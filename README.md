# Go (Golang): Explorando a Linguagem do Google

## 📖 Sobre

Este repositório contém meus estudos do curso **Go (Golang): Explorando a Linguagem do Google**.

O objetivo é aprender os principais conceitos da linguagem Go, desde a sintaxe básica até recursos mais avançados, aplicando-os por meio de exemplos e exercícios práticos.

---

## 🚀 Conteúdos Estudados

- Introdução à linguagem Go
- Instalação e configuração do ambiente
- Estrutura de um programa Go
- Variáveis e constantes
- Tipos de dados
- Operadores
- Entrada e saída de dados
- Estruturas condicionais (`if`, `switch`)
- Estruturas de repetição (`for`)
- Funções
- Arrays e Slices
- Maps
- Structs
- Ponteiros
- Métodos
- Interfaces
- Tratamento de erros
- Pacotes e módulos
- Concorrência com Goroutines
- Channels
- Boas práticas de desenvolvimento em Go

## ▶️ Como Executar

### Clone o repositório

```bash
git clone https://github.com/LucasDuarteV/golang-explorando-a-linguagem-do-google.git
```

### Acesse a pasta

```bash
cd golang-explorando-a-linguagem-do-google
```

### Execute um arquivo Go

```bash
go run nome_do_arquivo.go
```

### Ou compile o projeto

```bash
go build
```
